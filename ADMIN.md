# Панель контенту — ShoSho Trip

Панель живе на самому сайті за адресою **`/admin`** (наприклад
`https://shoshotrip.com/admin`). Через неї можна створювати й редагувати
**тури**, **команду** та **відгуки**.

Вхід — **лише пароль**, який ви задаєте самі при першому відкритті. Ніяких
акаунтів, токенів і бази даних.

---

## Перший вхід

1. Відкрийте `https://ваш-домен/admin`.
2. Панель побачить, що пароля ще немає, і запропонує його створити.
3. Придумайте пароль (від 10 символів), введіть двічі — і ви всередині.

**Зробіть це одразу після того, як сайт викладено.** Доки пароль не
встановлено, сторінка відкрита: перший, хто на неї зайде, задасть пароль собі.
Після встановлення форма створення закривається назавжди.

Якщо пароль забуто — скидання можливе лише через файловий менеджер Hostinger:
видаліть `admin.auth.php` у теці сайту, і панель знову запропонує створити
пароль.

---

## Як це працює

Сайт статичний — на хостингу лежать готові HTML-файли. Тому:

```
Ви редагуєте у /admin
        ↓ «Зберегти»
admin-api.php на вашому хостингу перевіряє пароль
        ↓
Зміни зберігаються у сховище контенту (репозиторій GitHub)
        ↓ автоматично, ~2 хвилини
Сайт перезбирається і заливається на Hostinger
        ↓
Зміни видно відвідувачам
```

Через це **між «Зберегти» і появою змін на сайті проходить близько двох
хвилин**. Це нормально, повторно зберігати не потрібно.

Побічний ефект корисний: кожне збереження — це запис в історії з датою. Будь-яку
зміну можна подивитися або відкотити.

Ключі доступу до сховища лежать **на сервері**, у файлі `admin.config.php`, і в
браузер не потрапляють. Тому вам достатньо пароля.

## Разове налаштування сервера

Робиться один раз тим, хто супроводжує сайт. Редактор цього не бачить.

### 1. `admin.config.php`

У теці сайту (`public_html/`) поруч із `admin-api.php` створіть файл
`admin.config.php` за зразком `admin.config.example.php`:

```php
<?php return [
  'GITHUB_TOKEN'  => 'github_pat_…',
  'GITHUB_REPO'   => 'loomloomapp-ops/shoshotrip',
  'GITHUB_BRANCH' => 'main',
];
```

Токен — fine-grained personal access token на GitHub:
**Settings → Developer settings → Personal access tokens → Fine-grained tokens**,
доступ **тільки до цього репозиторію**, дозвіл **Contents: read and write**.

Файл захищений через `.htaccess` і не потрапляє в репозиторій.

### 2. FTP-доступ для автозбірки

У репозиторії на GitHub: **Settings → Secrets and variables → Actions**:

| Секрет | Де взяти в Hostinger |
|---|---|
| `FTP_SERVER` | hPanel → Files → FTP Accounts → FTP hostname |
| `FTP_USERNAME` | там же, FTP username |
| `FTP_PASSWORD` | пароль цього FTP-акаунта |
| `FTP_DIR` | тека сайту, зазвичай `/public_html/` |

Краще завести **окремий FTP-акаунт** лише для цієї теки, а не використовувати
головний: відкликати доступ потім буде однією кнопкою.

Процес описано у [.github/workflows/deploy.yml](.github/workflows/deploy.yml),
стан збірок видно на вкладці **Actions**.

> Деплой навмисно не чіпає `admin.config.php`, `admin.auth.php` і
> `lead.config.php`. Інакше кожна збірка стирала б пароль і налаштування.

## Робота з панеллю

Угорі три розділи: **Тури**, **Команда**, **Відгуки**. Зліва список, справа
форма.

- **Додати** — новий запис.
- **Зберегти** — вгорі праворуч, активна лише коли є зміни.
- **Видалити** — у формі запису.
- Якщо є незбережені зміни, панель попередить перед виходом.

### Дві мови

Сайт двомовний, тому текстові поля показані парою: **Українською** і
**English**. Заповнюйте обидва — англійська версія бере текст із правого поля.
Якщо лишити порожнім, там буде порожньо.

### Фото

Біля кожного поля з фото є кнопка **Завантажити файл**.

- Стискайте фото **перед** завантаженням: знімок із телефона на 5 МБ зробить
  сайт повільним. Орієнтир — до 500 КБ, ширина близько 1600 px. Ліміт — 8 МБ.
- **HEIC із айфона не підійде** — браузери його не показують, і панель такий
  файл відхилить. Збережіть як JPEG.
- Фото обрізаються під формат блоку, тож головне тримайте ближче до центру
  кадру.

### Тури

- **Адреса сторінки** — частина посилання (`/ua/tours/morocco-atlas`).
  Заповнюється сама з назви, якщо лишити порожньою. **Після публікації міняти не
  варто** — старі посилання перестануть працювати, а сторінка втратить позиції
  в пошуку.
- **Дата початку** — формат `2026-11-14`. За нею тури сортуються.
- **Програма по днях** — кожен день розгортається натисканням: опис, маршрут,
  дорога, навантаження, харчування, ночівля, фото дня. Без свого фото день
  візьме кадр із галереї туру.
- **Демо-тур** — «Ні» для справжнього туру. «Так» позначає зразки для верстки.

### Команда

Блок «Хто їде з вами». Людей можна додавати скільки завгодно.

- **Кадрування фото** — картка обрізає знімок під горизонтальний формат.
  Для фото на весь зріст зазвичай підходить «Верх», для портрета — «Центр».
- **Особиста історія** — необов'язкова, кожен абзац окремо. Якщо порожня, кнопка
  «Читати історію» на сайті не показується.

### Відгуки

| Формат | Що заповнювати |
|---|---|
| Текстовий | текст, ім'я, фото автора |
| Відео | відео, обкладинка, ім'я |
| Скриншот | скриншот або текст |
| Фото | фото учасника, підпис у полі тексту |

**Instagram автора** — тільки якщо людина дозволила посилатися на профіль.

**Демо-відгук** — «Так» означає вигаданий зразок. Реальному відгуку обов'язково
ставте «Ні», інакше справжня людина позначена як вигадана.

## Якщо щось пішло не так

| Повідомлення | Що робити |
|---|---|
| «Забагато спроб» | Захист від підбору пароля: 8 невдалих спроб — і вхід закрито на 15 хвилин. Зачекайте. |
| «Панель ще не налаштована на сервері» | Немає `admin.config.php` — див. розділ «Разове налаштування». |
| «Токен GitHub недійсний або прострочений» | Термін токена вийшов. Створіть новий і замініть у `admin.config.php`. |
| «Дані змінилися паралельно» | Хтось редагував одночасно. Перезавантажте сторінку і внесіть правку заново. |
| «Дві однакові адреси сторінки» | Два тури з однаковим полем «Адреса сторінки». Змініть одне. |
| «Не знайдено admin-api.php» | Сайт викладено не повністю — бракує PHP-файлу в корені. |
| Збережено, але на сайті без змін | Зачекайте 2–3 хвилини. Якщо не з'явилось — вкладка **Actions** на GitHub покаже помилку збірки. |

## Що панель не змінює

Свідомо лишилось поза панеллю — це рідко змінюють і легко зламати:

- тексти головної, заголовки блоків, меню, підвал — `src/content/dictionaries.ts`;
- загальний FAQ — `src/content/faq.ts`;
- юридичні документи — `src/content/legal.ts`;
- галерея «Емоції» — `src/content/emotionsGallery.ts`;
- контакти й соцмережі — `src/content/config.ts`.

Будь-що з цього можна додати в панель: усі поля описані в одному місці —
`src/admin/schema.ts`.
